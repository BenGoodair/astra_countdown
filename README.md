# 📦 Don't Open The Box — Astra Shoe Countdown

A 5-hour hype countdown page for trail shoe arrival day. Built for runners, cyclists, and Devon Rex cat owners.

## 🚀 How to deploy to GitHub Pages

1. Create a new GitHub repo (e.g. `astra-countdown`)
2. Upload **both files** to the repo root:
   - `index.html`
   - `box.png`
3. Go to **Settings → Pages**
4. Under *Source*, select **Deploy from a branch**
5. Choose **main** branch, **/ (root)** folder → Save
6. Your page will be live at `https://YOUR-USERNAME.github.io/astra-countdown/` in ~1 min

## Features
- ⏱️ 5-hour countdown (starts fresh on each page load)
- 🏔️ Trail progress bar with running emoji
- 😼 Devon Rex cat chaos energy throughout
- 📱 Fully mobile-friendly
- 🎉 Big celebration screen when timer hits zero
- 🏃 Scrolling hype ticker
